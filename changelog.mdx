## August 2025

### Leadership Platform

- Resolved an issue where notes added to an employee’s contact page were visible on the web app but not appearing in the mobile app. Notes now display correctly across both platforms.

### Lebra Ascend

- Fixed an issue in the Observations section, under ‘General Observation Feedback,’ where the “Compose with Lebra” feature generated the same response regardless of the prompt entered. The function now correctly adapts to the user’s input, providing contextually relevant and concise responses both in Observations and under the Growth section.
- Addressed an issue where content from notes wasn’t consistently pulled on the first attempt. The system now reliably uses the user’s input to generate accurate suggestions and feedback on the initial try.

## July 2025

### Leadership Platform

- Adjusted the “short” message option to match the character limit for handwritten cards. Previously, the AI often generated messages that exceeded the allowed length.

## March 2025

- Started working on building Lebra Ascend - Lebra's newest Teacher Evaluations module

## February 2025

### Leadership Platform

- Resolved the issue where the blue “+” button was not functioning properly on the mobile app. Previously, users could temporarily fix this by uninstalling and reinstalling the app. This issue has now been fully resolved.

## October 2024

### Leadership Platform

- Addressed a bug that caused a delay between clicking the "We Connected" button and seeing the "Note added" confirmation. This latency should now be down to approximately 2-3 seconds.
- A potential fix has been implemented for the recurring issue with the "Add Person" button.
- Resolved an issue where editing a previous note/recognition would create an extra note with the same content.
- Addressed a UI issue where buttons in the Follow-up modal were overflowing from the modal window.
- Fixed a bug that caused follow-ups to be added with an incorrect date, one day ahead of the actual date.

## September 2024

### Leadership Platform

- Sent cards now update last interaction for Lebra Leadership Platform
- Product documentation is now available at docs.lebrahq.com
- Other visual polish and stability fixes.

### Organization AI

- File upload issues are now resolved.
- When uploading file, it's now clearer whether a file is uploaded for a specific user for your organization.
- Other visual polish and stability fixes.

### Before 2024

We were focused on planning, building, and bringing Lebra to life, so changelogs weren’t published during this period.
